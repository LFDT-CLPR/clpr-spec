# Release v0.2

**State:** Final

v0.2 is the baseline version of the CLPR Specification under [CLIP-0001](../clips/clip-0001.md). It is the version that the Early Access Program implementations target. It restates the EAP v0.2 text in the form CLIP-0001 defines, aligned with the implementations. **No CLIPs are integrated.**

## Known limitations

- The [open issues](../protocol/open-issues.md) list problems in the Protocol and Ledger Specifications that are left open in this version.
- The Hiero verifier API conveys a bundle's last message in the queue metadata, so a Hiero ledger receives a partial bundle as a run that ends at the sender's latest message, and accepts a bundle without messages only when it has received the sender's latest message ([Hiero Verifier API §5](../ledgers/hiero/verifier-api.md#5-last-message-in-the-queue-metadata)).
- Besu bundles are produced in the qbft-header scheme. The qbft-epoch scheme defines no configuration proof ([OI-2](../protocol/open-issues.md#oi-2-configuration-proof-format-for-the-qbft-epoch-scheme)).
- The recommended defaults in [CLPR Service §4](../recommendations/clpr-service.md#4-configuration-parameters) are the values the EAP implementations use; the EAP v0.2 text left them to be determined.
