# Release v0.2

**State:** Final

v0.2 is the baseline version of the CLPR Specification under [CLIP-0001](../clips/clip-0001.md). It is the version that the Early Access Program implementations target. It restates the EAP v0.2 text in the form CLIP-0001 defines, aligned with the implementations. **No CLIPs are integrated.**
